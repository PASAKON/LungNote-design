คลิกปุ่มเพื่อเปิด popup จริง — ทดสอบ interaction ได้เลย

1. Confirm Dialog
บันทึกการเปลี่ยนแปลง?
คุณแก้ไขโน้ตนี้แล้วแต่ยังไม่ได้บันทึก
ออกจากระบบ?
คุณจะต้อง login ใหม่อีกครั้ง
2. Delete / Destructive
ลบโน้ต "สรุปเคมี บท 5"?
การลบนี้ไม่สามารถย้อนกลับได้ โน้ตจะถูกลบออกจากทุกอุปกรณ์
ลบโฟลเดอร์ "ฟิสิกส์"?
โน้ต 12 รายการในโฟลเดอร์นี้จะถูกย้ายไปยัง "ไม่จัดหมวด"
3. Warning / Alert
Sync ไม่สำเร็จ
ไม่สามารถเชื่อมต่อ server ได้ โน้ตของคุณถูกบันทึกไว้ในเครื่องแล้ว
4. Success
บันทึกสำเร็จ!
โน้ต "สรุปเคมี บท 5" ถูก sync แล้วในทุกอุปกรณ์
5. Error
เกิดข้อผิดพลาด
ไม่สามารถสร้างโน้ตใหม่ได้ กรุณาลองใหม่อีกครั้ง

Error: NOTE_CREATE_FAILED (408)

6. Input Dialog
สร้างโฟลเดอร์ใหม่
ตั้งชื่อโฟลเดอร์สำหรับจัดกลุ่มโน้ต
ชื่อไม่เกิน 30 ตัวอักษร
เปลี่ยนชื่อโน้ต

ลองใหม่อัตโนมัติใน 5 วินาที
ใกล้ครบกำหนด!
